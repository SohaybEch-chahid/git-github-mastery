# Team Workflow

## Main Branch

Contains stable production code.

## Feature Branches

Each developer works in a separate branch.

Example:

```text
main
├── feature-login
├── feature-dashboard
└── bugfix-auth
```

## Workflow

1. Pull latest changes.
2. Create branch.
3. Develop feature.
4. Commit changes.
5. Push branch.
6. Open Pull Request.
7. Review code.
8. Merge.

## Benefits

- Reduced conflicts
- Better teamwork
- Easier maintenance
