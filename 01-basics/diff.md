# git diff

## Purpose

Show differences between files and commits.

## Syntax

```bash
git diff
```

## Example

Modify a file and run:

```bash
git diff
```

Git will display:

- Added lines
- Removed lines
- Modified lines

## Compare Staged Changes

```bash
git diff --staged
```

## Compare Commits

```bash
git diff COMMIT1 COMMIT2
```

## Notes
