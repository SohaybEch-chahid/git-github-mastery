# Forks

## What Is A Fork?

A fork is your personal copy of someone else's repository.

## Why Use Forks?

- Contribute to open-source projects.
- Experiment without affecting the original project.
- Create personal versions of projects.

## Fork Workflow

1. Fork repository on GitHub.
2. Clone fork locally.

```bash
git clone https://github.com/yourname/project.git
```

3. Make changes.
4. Push changes.
5. Create Pull Request to original repository.

## Benefits

- Safe collaboration
- Open-source contribution
